# Audio Limiter

闲来无事，玩游戏PUBG，发现游戏中武器的声音和脚步的声音响度差异巨大，容易炸耳朵，于是做了一个小工具，即能听清脚步又不至于让开火的声音炸耳朵！

Free Pasical开发，没什么可说的。

需要配合 [vb-cable](https://download.vb-audio.com/Download_CABLE/VBCABLE_Driver_Pack43.zip) 一起使用

操作系统选择 

        CABLE Input

本软件选择 

        上面 CABLE Output
        下面选择 实际的播放音箱、耳机  


注意

        CABLE Input
        CABLE Output
        音箱、耳机  
    中的 [属性] -> [高级] -> [默认格式] 一定要保持一样，要不没声音或出现其他故障
